ARCHITECTURE DECISIONS
----------------------

Paper mode:
  executor.place_order returns a synthetic OrderResult(filled_quantity=qty,
  average_price=entry_price) in PAPER mode so that _execute_single_entry
  creates real in-memory positions. Previously paper returned None and no
  positions were tracked. This was fixed when tick entry was added.

Backtest parity rule:
  Backtest must use the same scan_symbols, should_enter_trade,
  resolve_trade_targets, and engine position builders as live/paper.
  Never invent a parallel stop/target path in backtesting.py.

Tick entry design:
  The tick entry system is additive and safe. The closed-candle scan loop
  runs first. Tick entry only monitors candidates not yet entered. If the
  WebSocket is unavailable it falls back to REST LTP polling. If REST also
  fails, the next closed-candle cycle handles entry normally.
