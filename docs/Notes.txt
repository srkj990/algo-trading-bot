Strategy Reference Notes
========================

Practical notes on when each strategy works and when it fails.
Use this before tuning parameters or blaming the bot for a loss.


1. Moving Average (MA)
----------------------
Logic:
  - MA20 = short-term trend
  - MA50 = longer-term trend
  - BUY when MA20 > MA50
  - SELL when MA20 < MA50

What it captures: trend direction
Works best in: trending markets (strong directional move)
Fails in: sideways / choppy markets (frequent false crossovers)
Intuition: "Follow the trend, don't predict it"

In this bot: confirm_signal() requires both the previous and current
candle windows to agree, so effective first actionable is candle 51.


2. RSI (Relative Strength Index)
---------------------------------
Logic:
  - RSI range 0-100
  - BUY when RSI < 30 (oversold)
  - SELL when RSI > 70 (overbought)

What it captures: momentum exhaustion
Works best in: sideways / range-bound markets
Fails in: strong trends (RSI can stay extended for a long time)
Intuition: "Too much of anything reverses"

In this bot: 14-period RSI by default. Effective first actionable: 15.


3. Breakout
-----------
Logic:
  - Look at the previous 20 completed candles
  - BUY if current close > prior 20-candle high
  - SELL if current close < prior 20-candle low

What it captures: new momentum / volatility expansion
Works best in: markets starting to move after consolidation
Fails in: fake breakouts (price breaks the level and immediately reverses)
Intuition: "Big moves start after quiet periods"

In this bot: volume confirmation is applied in intraday equity to require
that current volume >= matched prior-day average * 1.2.
Effective first actionable: candle 22 (confirm_signal overhead).


4. VWAP
-------
Logic:
  - VWAP = cumulative volume-weighted average price
  - BUY when price > VWAP
  - SELL when price < VWAP

What it captures: institutional bias
Works best in: intraday trading with active volume
Fails in: choppy markets where price oscillates around VWAP repeatedly
Intuition: "Smart money trades around VWAP"

In this bot: VWAP bias also acts as a gate for intraday options entries
and as a filter inside auto-adaptive intraday equity.


5. ORB (Opening Range Breakout)
--------------------------------
Logic:
  - Opening range = first 15 candles of the session (09:15-09:30)
  - BUY if price breaks above the opening range high
  - SELL if price breaks below the opening range low

What it captures: early market direction setting
Works best in: strong opening trends
Fails in: flat opens / fake early moves that reverse after 30-60 minutes
Intuition: "The first move of the day often defines the direction"

In this bot: strategy_orb() slices session_df by row position starting
from 09:15 IST. The session_df must start at 09:15 for the range to
be accurate.


Strategy Choice by Market Condition
-------------------------------------
  Trending market:  MA, Breakout
  Sideways market:  RSI
  Intraday:         VWAP, ORB
  Unknown:          AUTO_ADAPTIVE (let the engine decide)

No strategy is best in all conditions. The auto-adaptive mode exists
precisely because different days require different approaches.


Multi-Strategy Confirmation
----------------------------
Using a single strategy in isolation produces noisy signals.
Multi-strategy mode requires N out of M chosen strategies to agree
before an entry fires. Combining complementary strategies reduces
false signals:

  MA + RSI     -> trend confirmation + momentum filter
  Breakout + VWAP -> breakout only in the direction institutions favor
  VWAP + ORB   -> intraday strength confirmed by both directional inputs

In the bot, set strategy mode to MULTI and choose min_confirmations >= 2.


Live Session Operational Notes (2026-06-02)
--------------------------------------------
Exit Orders (Kite F&O API requirements):
  - Raw MARKET orders are rejected for F&O. All exits now use LIMIT with 1% buffer.
  - Limit prices must be multiples of ₹0.05 (NSE tick size). executor.py rounds automatically.
  - Exit product must match position product. NRML reconciled positions exit as NRML.

Manual Position Pickup:
  - In LIVE mode, bot polls broker every 60 seconds (live_broker_resync_interval_seconds).
  - Manually opened positions are detected and added to algo management automatically.
  - Only adds new positions; never removes algo-managed ones mid-session.
  - Log: [RECON] Runtime sync detected manual broker position: <symbol>

Reconciliation:
  - Startup reconcile now includes both MIS and NRML options positions.
  - Product stored in position["order_product"] at reconciliation, used for all exits.

Kite IP Allowlist:
  - Run auto_auth.py to refresh token. It now prints your public IP automatically.
  - Add that IP in Kite developer console → App Settings → Allowed IPs.
  - IP changes on router restart or ISP reconnect — re-run auto_auth.py to get new IP.

Runner CWD:
  - Each runner in runners/ sets CWD to its own folder.
  - .env is found automatically via config.py-relative path fallback.
  - state/ and logs/ are created inside the runner folder (isolated per engine).

Backtest Notes:

  - intraday_options backtest always uses LEGACY_RAW entry regardless of live entry mode setting.
  - Tick simulation in backtest models intra-candle fills using option candle OHLC.


Intraday Options Strategy Notes
---------------------------------
Intraday options strategies emit BUY_CE, BUY_PE, or NO_TRADE.
The underlying spot signal drives option type selection.

ATM_MOMENTUM:
  - Strong directional signal required
  - CE for bullish, PE for bearish
  - Staged entry: confirmation candle + pullback re-entry
  - Fails when market whipsaws around VWAP

ATM_ORB:
  - Clean directional bias after the opening range
  - Works best on gap-and-go days
  - Fails on fake ORB breaks that fill back into range

ATM_BREAKOUT_EXPANSION:
  - Requires 45 candles to establish compression + breakout + volume + ATR expansion
  - High quality but fires less frequently
  - Best for sustained moves; fails on thin-volume breakouts

ATM_TRAP_REVERSAL:
  - Trades failed breakouts
  - Requires both a trap candle sequence and a strong reversal body
  - Counter-trend; keep position sizing conservative
